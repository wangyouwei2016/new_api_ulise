# 使用政策

为维护平台健康、安全与合规运行，所有使用 维格智创Token站 服务的用户必须遵守以下使用政策。

## 禁止行为

用户不得利用本服务从事以下任何活动：

1. **违法违规内容**：生成、传播违反适用法律法规或危害公共安全的内容。
2. **恶意攻击与滥用**：制作恶意软件、实施网络攻击、钓鱼欺诈或绕过安全防护机制。
3. **侵犯他人权益**：未经授权冒充他人身份、侵犯知识产权或非法收集个人隐私。
4. **滥用平台资源**：恶意转售共享高危账号、规避计费逻辑或发起拒绝服务攻击。

## 违规处理

一经发现违反本政策的行为，平台有权视情节轻重采取警告、限制速率、暂停接口调用或永久封禁账号等措施。
