# 服务特定条款

本文件补充说明特定能力模块（包括大语言模型转发、多模态生成与企业线路）的专项约定，与 [服务条款](/terms-and-conditions/terms) 共同构成完整协议。

## 1. 上游模型服务约定

本平台聚合多家第三方 AI 模型提供方。使用对应模型时，你同时应遵守相应上游供应商的内容安全规范与输出使用限制。

## 2. 速率限制与公平使用

- 为保障全体用户的稳定访问，平台可能对单账号或单令牌实施并发数、RPM（每分钟请求数）或 TPM（每分钟 Token 数）限制。
- 禁止使用自动化脚本对接口进行压测、恶意刷量或绕过鉴权与限流策略。

## 3. 预览版与实验性模型

标注为 `preview`、`beta` 或实验性的模型可能随时发生行为变化或下线，不建议直接用于对稳定性要求极高的生产关键链路。
