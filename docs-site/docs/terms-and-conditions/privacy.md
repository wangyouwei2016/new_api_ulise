# 隐私政策

维格智创Token站 重视你的隐私与数据安全。本政策说明我们在你使用本服务时如何收集、使用与保护相关信息。

## 1. 我们收集的信息

- **账号信息**：注册邮箱、用户名及必要的身份认证凭据。
- **调用元数据**：请求时间、调用模型、Token 消耗量、状态码及延迟等，用于计费对账与故障排查。
- **支付与账单记录**：充值订单号、金额与入账状态（不包含完整银行卡敏感信息）。

## 2. 请求内容处理原则

- 除非为了排查你主动反馈的技术故障或法律法规强制要求，平台默认不将你的对话内容用于模型训练。
- API 请求在传输过程中全程使用 HTTPS/TLS 加密。

## 3. 数据存储与安全措施

我们采用访问控制、密钥哈希与最小权限原则保护账户数据与日志信息。你可随时在控制台删除不再使用的 API 令牌或申请注销账号。
